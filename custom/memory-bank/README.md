# Memory bank

Plain-markdown project memory so any Claude session (or human) can resume cold.

| File | Purpose | Update when |
| --- | --- | --- |
| `activeContext.md` | what we're doing now, next 1–3 steps, open questions | every session end |
| `decisions.md` | decisions + reasons (append-only log) | a choice is made |
| `../progress.md` | done / not done / run instructions / lessons | state of the system changes |

Rules: no secrets, no passwords, no IPs. Dates absolute (YYYY-MM-DD). Mark facts *(verified)* or *(assumed)*. Keep each file short; archive old entries rather than growing forever.
